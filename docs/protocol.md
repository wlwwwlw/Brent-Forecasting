# Как мы сравнивали модели

Мы прогнозируем дневную цену закрытия на 1 и 5 торговых сессий. Все модели получают только прошлые close. Даты прогнозов внутри каждого горизонта совпадают.

## Временное разделение

| Часть | Последняя известная сессия: индексы | Даты | Прогнозов на горизонт |
|---|---|---|---:|
| Первая обучающая история | 0–99 | до 18.03.2026 | 100 цен |
| Валидация 1 | 99–132 | 18.03–05.05.2026 | 34 |
| Валидация 2 | 133–166 | 06.05–22.06.2026 | 34 |
| Валидация 3 | 167–202 | 23.06–11.08.2026 | 36 |
| Тест | 207–252 | 18.08–20.10.2026 | 46 |

Индексы начинаются с нуля. Валидация нужна для выбора настроек, тест — для оценки уже выбранных моделей. Все пары «дата прогноза → дата цели» записаны в `config/split_manifest.csv`.

Последний прогноз валидации на 5 сессий проверяется ценой с индексом 207. Только после неё можно выбрать победителей по всей валидации. Поэтому тест начинается с известной цены 207; точки 203–206 в оценку не входят.

В тесте одинаковые даты выпуска прогнозов для двух горизонтов. Целевые даты h=1 и h=5 различаются на четыре сессии. Внутри горизонта фактическая цена одинакова для всех моделей.

## Защита от будущего

В момент t функция обучения получает только `close[:t+1]`. Для обучающего примера j на горизонте h требуется **j+h ≤ t**: целевая цена уже должна быть известна. Признаки используют только цены до j.

ML и сети начинают обучающие примеры с j=20: для 20 изменений нужна 21 цена. На первой точке прогноза доступно 79 примеров для h=1 и 75 для h=5. Средние и масштабы X/y считаются только по этим примерам. Текущее окно прогноза в обучение scaler не входит.

На каждой новой сессии мы обучаем модель заново на расширенной истории. Уже известные тестовые цены использовать можно; выбирать новые настройки по тестовым ошибкам нельзя. В пятишаговый статистический прогноз будущие фактические цены не подставляются.

## Выбор моделей

Мы выбрали настройки по минимальному RMSE на всех 104 валидационных точках. При точном равенстве — по MAE, затем по имени конфигурации. У сетей сравнивали среднее RMSE трёх запусков с seed 7, 42, 2026. Основной тестовый seed=42 задан заранее; остальные результаты также опубликованы.

Победителей и правила теста записали в `config/final_lock.json` до тестового расчёта. В финал вошли Naive, SES, ElasticNet и LSTM/RNN для горизонтов 1/5. Неполный набор прогнозов исключает кандидата из выбора целиком.

## Метрики и устойчивость

- **MAE:** средняя абсолютная ошибка, USD/баррель.
- **RMSE:** корень из средней квадратичной ошибки, USD/баррель. Сильнее штрафует крупные промахи.
- **sMAPE:** среднее `200·|прогноз−факт|/(|факт|+|прогноз|)`, проценты. Для двух нулевых цен вклад равен нулю.
- **DA:** доля совпадений знака прогнозного и фактического изменения. Нулевое изменение имеет знак 0. Дополнительно сохраняем долю ненулевых сигналов — coverage.

Мы проверили три блока валидации, две половины теста, три seed сетей и влияние крупнейших ошибок. Для разницы RMSE с Naive использовали парный блочный bootstrap: 10 000 повторов, блоки 5 и 10, seed 20261104. В каждом повторе у пары моделей берутся одни и те же блоки дат.

Блоки сохраняют часть зависимости соседних ошибок; на горизонте 5 дни перекрываются. При 46 точках интервалы приблизительны, без поправки на несколько сравнений. Интервал с нулём не подтверждает преимущество и не доказывает равенство.

Все результаты первого эксперимента сохранены. Полная H1-проверка ряд не изменила. Новые диагностические срезы не считаем новым независимым тестом и по ним модели не перенастраиваем.
